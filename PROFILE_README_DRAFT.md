## Featured projects

### 🚗 Smart ADAS — Real-Time Vehicle Safety & Driver Assistance
An RC-car-based test prototype exploring driver-assistance concepts, sensor inputs, and computer vision.

**Technologies:** ESP32, ESP32-CAM, Python, OpenCV, MediaPipe, NumPy, HC-SR04 ultrasonic sensors, MPU6050, GPS.

[Open repository](https://github.com/vedantsatpute25/Smart-ADAS) · *Repository is currently private.*

### 🛡️ VoiceShield AI
A prototype exploring AI-assisted analysis of suspicious voice recordings and vishing indicators by combining audio classification, transcription, and transcript-based checks.

**Technologies used in the prototype:** Python, FastAPI, pretrained audio classification, faster-whisper, SQLite.

### 📱 Health Manager
An Android application for tracking everyday wellness activities such as water intake, workouts, diet/calorie logs, steps, and progress.

**Technologies:** Java, XML, Firebase Authentication, Firebase Realtime Database.

### 🗓️ Attendance Management Application
An Android-based attendance app with login, attendance marking, history, attendance percentage calculation, and reports.

**Technologies:** Firebase Authentication, Firebase Realtime Database.

### 📄 AI Resume Screening System
A workflow automation project designed to extract resume information, support candidate screening, and streamline follow-up steps.

**Technologies:** Microsoft Power Automate Desktop (PAD), Excel, PDF/text extraction, AI/API integration.
