## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser to inspect the static page.
3. If the page uses browser features that require a local server, run:

   ```bash
   python -m http.server 8000
   ```

   Then open `http://localhost:8000`.

## Deployment

A `netlify.toml` file is present. Review its settings and connect the repository to the intended Netlify site before assuming deployment is active.
